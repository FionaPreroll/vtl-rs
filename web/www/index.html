VTL-2 in short

10 A=1stores line 10; 10 alone deletes it; 0 lists the program
?=A ?="HI"prints a number or text; ?="HI"; keeps the line open
A=? A=$ $=65reads a number or a key, prints a character
#=100goes to line 100; #=0 does nothing, so #=X>5*100 is an IF
#=!returns to the line after the last jump
:I)=5array element I, in memory from & up to *
+ - * / = < >strictly left to right; > is ≥; % is the last remainder
' & *a random number, the end of the program, the end of memory
)a comment

Commands: RUN, LIST, NEW, SAVE name, LOAD name (in this browser), DIR, CLS, HELP. Ctrl-C or Esc stops a program, ↑ and ↓ bring back earlier lines.

The whole language: docs/language.md. The source and the command line program for Linux, macOS and Windows: github.com/FionaPreroll/vtl-rs.
